# Division typography

These fonts are bundled with the game; no font service or external stylesheet is required at runtime.

- **Anton** — condensed game headings and major actions. Upstream: https://github.com/google/fonts/tree/main/ofl/anton . License: `anton-OFL.txt`.
- **Courier Prime** — readable vintage-style menu descriptions, controls, fighter labels, and numbers. Upstream: https://github.com/google/fonts/tree/main/ofl/courierprime . License: `courier-prime-OFL.txt`.

Downloaded from the official Google Fonts repository on 2026-11-05. Font files are unmodified. The illustrated Division logo in `../art/ui/division-logo.webp` is a transparent title asset. Keep both license files with redistributions, including native builds.
