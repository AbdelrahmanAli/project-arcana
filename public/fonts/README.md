# Division typography

These fonts are bundled with the game; no font service or external stylesheet is required at runtime.

- **Jersey 10** — pixel display headings, countdown, and main menu actions. Upstream: https://github.com/google/fonts/tree/main/ofl/jersey10 . License: `jersey-10-OFL.txt`.
- **VT323** — retro terminal lettering for menu descriptions, controls, fighter labels, and numbers. Upstream: https://github.com/google/fonts/tree/main/ofl/vt323 . License: `vt323-OFL.txt`.

Downloaded from the official Google Fonts repository on 2026-11-05. Font files are unmodified. Keep both license files with redistributions, including native builds.

Both faces use their native regular weight. UI labels are enlarged to preserve readability on phones; hard offset shadows keep the lettering crisp.
