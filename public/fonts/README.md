# Division typography

These fonts are bundled with the game; no font service or external stylesheet is required at runtime.

- **Black Ops One** — display headings, countdown, and main menu actions. Upstream: https://github.com/google/fonts/tree/main/ofl/blackopsone . License: `black-ops-one-OFL.txt`.
- **Oxanium** — variable weight 200–800, menu descriptions, controls, fighter labels, and numbers. Upstream: https://github.com/google/fonts/tree/main/ofl/oxanium . License: `oxanium-OFL.txt`.

Downloaded from the official Google Fonts repository on 2026-11-04. Font files are unmodified. Keep both license files with redistributions, including native builds.
