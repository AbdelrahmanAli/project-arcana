# Alarm sound

`red-alert-nuclear-buzzer.mp3` is the high-quality preview of “Red Alert_Nuclear_Buzzer.mp3” by imagery2 on Freesound:
https://freesound.org/people/imagery2/sounds/458570/

The creator released it under CC0 1.0. It is an independent sound effect, not audio from Command & Conquer: Red Alert 2. The game plays only the first 3.7 seconds once when the tower begins to rise.
