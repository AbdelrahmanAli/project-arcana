# Phase 4 art: Healing syringe

The healing pickup is [`public/art/healing-syringe.png`](../public/art/healing-syringe.png), a 1536 × 1024 transparent PNG generated with the built-in imagegen tool. The original RGBA output was copied into the project without replacing any existing art. PixiJS scales it to the in-game pickup size.

## Final generation prompt

> Use case: stylized-concept. Asset type: transparent game pickup sprite for a detailed 2D arcade pixel-art combat game, seen from a slightly elevated top-down angle. Primary request: one futuristic battlefield healing syringe, compact and instantly recognizable at small in-game scale. A single thick medical injector with a short capped needle, metallic graphite body, ivory grip details, and luminous emerald-green medicine chamber. Crisp hand-placed pixel clusters, dark precise outline, bright readable highlights, strong silhouette and restrained glow within the object. Centered isolated object with generous transparent padding, slight diagonal incline matching weapon pickups, no cast shadow. Transparent background with genuine alpha. Constraints: exactly one syringe, no text, no labels, no logos, no other objects, no ground, no borders, no checkerboard.

The crate opening motion, healing burst, and floating health number are drawn by game code so they remain aligned with the pickup and fighter.
